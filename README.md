# wow-icons
Here you will find a work-in-progress collection of **World of Warcraft** icons for projects. All of the current collection was sourced from a public repository.

## What you can expect to find:
- Class icons
- Class crests
- Spec icons
- Other misc WoW icons

*Expect folder reorganization as the collection grows*
